# Portfólio profissional — Carlos Henrique Cintra

Site estático preparado para **GitHub Pages**, com foco em apresentar projetos, trajetória, formação e competências para recrutadores, empresas e equipes de design/marketing.

## Arquivos principais

- `index.html` — conteúdo, projetos, perfil, formação, competências e contatos.
- `styles.css` — identidade visual e layout responsivo.
- `script.js` — menu mobile, filtros de projetos, barra de leitura e visualização ampliada das imagens.
- Imagens `.webp` e arquivos `.svg` — fotografias, trabalhos, padrão de azulejo e favicon.
- `404.html` — página para endereços não encontrados.
- `robots.txt` e `sitemap.xml` — configuração básica para mecanismos de busca.
- `.nojekyll` — evita processamento desnecessário pelo Jekyll.

## Publicar no GitHub Pages

1. Extraia o ZIP.
2. Abra o repositório `Alem4oo0/portifolioo`.
3. Use **Add file → Upload files**.
4. Envie todos os arquivos extraídos diretamente para a raiz do repositório, substituindo a versão anterior.
5. Faça o commit na branch `main`.
6. Mantenha o GitHub Pages configurado para publicar a branch `main`, pasta `/(root)`.

Não envie o ZIP fechado e não coloque o site dentro de uma pasta extra.
